# Descargas de Mercado Simple

Instaladores oficiales y acceso a la app web de Mercado Simple. El código fuente principal permanece en el repositorio privado; este repositorio de descargas no contiene bases de datos, credenciales ni información de empresas.

[Ir a la página de instalación de Mercado Simple](https://mercado-simple-production.up.railway.app/descargas).

- [Windows 1.1.6, 64 bits](https://github.com/JGGallardo/mercado-simple-descargas/releases/tag/v1.1.6): instalador para Windows 10/11, con Plan Base independiente, servidor del comercio y facturación directa desde la PC a ARCA.
- [Android 1.0.0](https://github.com/JGGallardo/mercado-simple-descargas/releases/tag/android-v1.0.0): APK firmado para Android 8 o posterior. Usa las mismas cuentas y permite configurar explícitamente nube o servidor local HTTPS.
- iPhone/iPad: abrir Mercado Simple en Safari y elegir Compartir → Añadir a pantalla de inicio. No requiere App Store ni Apple Developer.

Para operar sin internet en el comercio, la PC servidor debe estar encendida y autorizada, el celular conectado al Wi-Fi local y el certificado público configurado. La instalación realizada desde la nube sigue abriendo la nube; no cambia automáticamente al servidor local.

Cada release incluye el instalador y su SHA-256. La impresión directa NIIMBOT USB/Bluetooth desde Android no está incluida en esta primera versión móvil.
